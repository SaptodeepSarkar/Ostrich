# Style references

User-supplied photographs used as the visual target for the Ostrich "Pebble"
material. They are **reference only** — not shipped assets, not loaded at
runtime, and not derived from any GPL project.

| File | Subject | What to take from it |
| --- | --- | --- |
| `pebble-clock-0006.jpg` | `00:06` on a dark lock screen | inflated rounded digits, white rim light, violet-to-pink gloss |
| `pebble-clock-0806.jpg` | `08:06` | bloom around the highlights, soft ambient glow, deep black canvas |
| `pebble-clock-1058.jpg` | `10:58` | iridescent gradient across a single pebble, specular hotspot top-left |

Shared traits: pitch-black background, one giant pebble-like display element,
glossy translucent surface, bright rim/specular highlights, colored ambient
bloom, no hard edges, generous empty space.

Companion inspiration: [glyph-rice](https://github.com/Nebelung-cloud/glyph-rice)
(GPL-3.0, studied read-only): radial session dial, dot-matrix clock numerals,
floating rounded cards, monochrome base with a single accent, edge-anchored
indicators, staged greeter animation. We reimplement the *ideas*; no code,
assets, fonts, or strings are copied.

Design rules live in [../../DESIGN.md](../../DESIGN.md).
